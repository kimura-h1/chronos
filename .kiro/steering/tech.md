# Tech Steering

- Frontend: React 19 + TypeScript + Vite + Tailwind CSS v4 + React Three Fiber (three.js) + Recharts
- Backend: Python 3.12 + FastAPI + NumPy + SciPy + SymPy (+ mpmath for high-precision reference values)
- Test: pytest（物理エンジン・API）, Playwright（ブラウザ操作E2E）
- 単位系: 幾何単位 c = G = 1。計量符号 (−,+,+,+)。
- 物理換算: スケール a を光年で与えると、時間は年、長さは光年で表示する。
- Docker Composeは不要（ローカル開発サーバーで完結）。
